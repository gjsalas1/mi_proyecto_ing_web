CONTROL DE VERSIONES

¿Qué es Git?

Git es un sistema de control de versiones distribuido. Permite registrar los cambios de tus archivos, recuperar versiones anteriores y trabajar con diferentes ramas.

  • Historial de cambios
  • Creación de ramas
  • Trabajo sin conexión

●
COLABORACIÓN EN LA NUBE

¿Qué es GitHub?

GitHub es una plataforma para alojar repositorios Git. Facilita compartir código, revisar cambios, gestionar proyectos y colaborar con otros desarrolladores.

  • Repositorios remotos
  • Pull requests
  • Trabajo en equipo

APRENDE PRACTICANDO

Comandos básicos de Git

Selecciona un comando y copia el código para probarlo en tu terminal.

bash — comandos Git
git init Inicializa un repositorio
git clone URL Clona un repositorio remoto
git status Muestra el estado de los archivos
git add . Prepara los cambios para guardarlos
git commit -m "mensaje" Guarda una versión en el historial
git pull Obtiene e integra cambios remotos
git push Publica tus commits en el remoto

Tu flujo de trabajo

⌘

02
✎

Realiza cambios

03
✓

Prepara los archivos con git add y registra los cambios.

04
↑

05
