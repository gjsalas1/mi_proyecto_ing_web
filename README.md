# Git & GitHub - Ingeniería Web

## Descripción
Esta página web educativa tiene como objetivo dar a conocer los conceptos básicos de Git y GitHub, sus principales características, comandos esenciales y su importancia en el desarrollo de software y el trabajo colaborativo.

## Tecnologías utilizadas
- **HTML5:** estructura y contenido de la página.
- **CSS3:** diseño, colores, animaciones y adaptación a dispositivos móviles.
- **JavaScript:** interactividad, copia de comandos, consejos y cuestionario.

## Funcionalidades
- Información sobre Git y GitHub.
- Ejemplos de comandos básicos de Git.
- Botones para copiar comandos.
- Consejos para desarrolladores.
- Cuestionario interactivo para evaluar conocimientos.
- Menú de navegación adaptable a dispositivos móviles.

## Estructura del proyecto
- `index.html`: página principal.
- `estilos/style.css`: estilos y diseño visual.
- `js/script.js`: funciones interactivas.
- `README.md`: documentación del proyecto.

## Autor
Proyecto académico de la asignatura Ingeniería Web.

## Objetivo
Aprender y demostrar el uso de HTML, CSS y JavaScript mediante el desarrollo de una página web informativa sobre Git y GitHub.
